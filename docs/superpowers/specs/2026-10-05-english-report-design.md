## 1. 英文报告：`jianjin check --lang en`

- 双语文字：`types.py` 加 `Bi`，它是 `str` 的子类。当普通字符串用时就是中文，`.en` 是英文；`en(x)` 取英文，没有英文时退回原文。证据、判定理由、没查的原因都用它生成：中英两份写在同一处、用同一组数算出来，不经过模型。老代码和老测试照旧把它当中文字符串用。
- `NotApplicable` 的原因用 `reason(exc)` 取，不再用 `str(exc)`，免得把英文丢掉。
- 名称表放进新文件 `i18n.py`：原因、规则、来源、判定的中英名。`summary.py` 的 `CAUSE_EN`、`CHECKS` 搬过去，`summary.py` 从那里引用。
- `report.render` 加 `lang`：
  - 界面文字查表；`en` 时 `<html lang="en">`；
  - 本批小结在 `en` 时先英文、后中文；
  - 筛选按钮的内部值改用 `pass`、`doubt`、`reject`，不再用中文判定名。
- 命令行：`--lang en` 时终端打印也用英文，因为录屏要拍终端。
- 页脚原来写「错杀一条好数据比漏掉一条坏数据贵」，这是取舍，不是事实。中英两份都改成「判得偏保守是取舍：好示范很少被错杀，代价是有些坏示范会判合格」。
- 测试：
  - 每条规则的证据，中英两份抽出来的数字序列相同；
  - 英文报告除了中文小结那一段，没有汉字；
  - 判定理由、没查的原因都有英文。

## 2. 换档关键帧
